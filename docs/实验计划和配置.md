# 实验计划和配置

日期：2026-08-26  
状态：B0、B1、B1T、B2 已实现；等待使用修正后的教师输入重新训练。

## 1. 当前主线

B1 是主基础，其他实验只做相对 B1 的单项加减。

| 实验 | 相对 B1 的变化 | 目的 |
| --- | --- | --- |
| B0 | 去掉 teacher value，所有 effective GT 使用 `q=1` | full-GT uniform 对照 |
| B1 | 无 | 主基础：teacher-value、圆形 Gaussian、不放缩 |
| B1T | 只把圆形 Gaussian 改为有方向椭圆 Gaussian | 验证 mask 形状 |
| B2 | 只增加 AdaptiveGTScalerV3 | 验证 GT geometry 扩张 |

重叠区域统一取最大值：

```text
overlap_merge = max
```

科学对比只允许以下差异：

```text
B0 - B1：region.value
B1T - B1：region.mask.type
B2 - B1：region.scaler.enabled
```

## 2. B1 定义

匹配规则：

```text
exact-class-only
small distance < 1m
large distance < 2m
score-first nearest-unmatched GT
one-to-one
```

Small 类别：

```text
barrier, motorcycle, bicycle, pedestrian, traffic_cone
```

Large 类别：

```text
car, truck, construction_vehicle, bus, trailer
```

匹配后实例价值：

```text
r_i = d_i / tau_i
q_i = max(0, 1 - r_i^2)
unmatched q_i = 0
```

B1 使用 BDA 后的原始 GT 生成圆形 Gaussian，不调用 AdaptiveGTScaler。Feature loss 使用 per-GT fixed-count reduction，分母为 effective GT 数，不能改为 `sum(q)` 或 `mask.sum()`。

## 3. B0、B1T、B2

### B0

所有 effective GT：

```text
q_i = 1
```

Teacher backbone feature 仍作为 KD target，response KD 等公共路径不变。Teacher proposal 不决定 feature ROI 的筛选、价值或几何。

### B1T

完全复用 B1 的 matching、`q`、GT geometry、loss 和训练参数，只将：

```text
per_gt_gaussian
```

替换为：

```text
per_gt_elliptical_gaussian
```

### B2

完全复用 B1，只启用：

```text
region.scaler.enabled = true
```

Scaler 只能改变 feature ROI 的空间几何，不能改变 matching、`q`、effective GT 或 loss 分母。

## 5. 固定数据口径

学生使用：

```text
当前图像帧 + [-2, -4, -6, -8]，共 5 个时刻
```

教师使用：

```text
当前 LiDAR sweep + 过去 9 个 LiDAR sweeps，共 10 sweeps
```

历史 LiDAR 全部变换到当前帧坐标系，`time_lag = current_timestamp - sweep_timestamp`，禁止使用未来 sweep。历史不足时用当前 sweep 补足到 10。

当前 info：

```text
data/nuScenes/nuscenes_infos_train_10sweeps_past9.pkl
data/nuScenes/nuscenes_infos_val_10sweeps_past9.pkl
```

BDA 对 GT 与教师 LiDAR 的完整 xyz 使用同一 `3×3` 旋转、缩放和翻转矩阵；反射率和时间通道不变。

旧 info 中“过去 5 + 未来 5”的混合方式已废弃。

## 8. 当前结果解释边界

以下旧结果不能作为当前 B1/B2 的正式结论：

- 使用旧教师或 step 50200 教师的结果；
- 使用旧混合 future-sweep info 的结果；
- BDA 未对齐时训练的结果；
- response bbox KD 未修复时训练的结果；
- feature weight 不是 1.0 的结果；
- train/val 混合训练后再在 val 上报告的教师结果。

因此 B0、B1、B1T、B2 都需要基于当前口径重新训练和验证。
