# 训练命令汇总

> 所有命令均在**项目根目录** `ROI_LABEL_DISTILL/` 下执行。
> 入口为各实验 `.py` 文件本身（内部调用 `run_cli`）。

## 通用说明

所有实验脚本统一支持以下参数：

| 参数 | 含义 | 默认值 |
|---|---|---|
| --batch_size_per_device | 每张 GPU 的 batch size | 2 |
| --gpus | GPU 数量 | 8 |
| --default_root_dir | checkpoint 与训练日志根目录 | /mnt/nas_data/guqiupeng/checkpoint_nes/<exp_name>/ |
| --checkpoint | 恢复训练或测试使用的 checkpoint | 无 |
| -e / --evaluate | 验证模式 | false |
| -p / --predict | 测试集推理并导出结果 | false |
| --test_output_dir | 显式指定测试结果目录 | 自动生成 |
| --seed | 随机种子 | 0 |

产物路径约定：

- 训练 checkpoint：/mnt/nas_data/guqiupeng/checkpoint_nes/<exp_name>/checkpoints/，保存 top-3 checkpoint 和 last.ckpt。
- checkpoint 文件名统一为 epoch_<N>.ckpt，例如 epoch_19.ckpt。
- 测试结果默认：/mnt/nas_data/guqiupeng/checkpoint_nes/test_answer/<exp_name>/<checkpoint_name>/run_YYYYMMDD_HHMMSS/。
- 如需迁移根目录，可设置环境变量 LABELDISTILL_CHECKPOINT_ROOT；如需单次覆盖测试目录，使用 --test_output_dir。

---|---|---|
| `--gpus` | 单节点 GPU 数 | 1 |
| `-b` / `--batch_size_per_device` | **单卡** batch size | 8 |
| `--max_epochs` | 训练 epoch 数 | 取实验内 `epochs` 配置 |
| `--precision` | 混合精度（16/32） | 16 |
| `--default_root_dir` | 输出目录 | `./outputs/<exp_name>/` |
| `-e` / `--evaluate` | 验证集评测（`trainer.test`） | - |
| `--ckpt_path` | 加载/续训权重 | - |
| `--seed` | 随机种子 | 0 |

- 输出目录自动命名为 `./outputs/<实验文件名>/`，checkpoint 在其 `checkpoints/` 子目录（保留 top-3 + last）。
- 有效总 batch = `--gpus × -b`。下方命令给出推荐配置，显存不足时调小 `-b`。

## 一、主实验：ConvNeXt-B + Adaptive GT Scaling + CBGS + 时序 KD

```bash
python labeldistill/exps/lidardistill_convnextb_900x1600_J4_wl05_wh08_cbgs.py   --batch_size_per_device 2   --gpus 8
```

主要配置：

- 图像骨干：ConvNeXt-B；
- 输入尺寸：900 x 1600；
- AdaptiveGTScalerV3：offset 与 velocity 已统一转换到 box-local frame，V3 不再使用 base floor；
- 尺度参数：w_l=0.5，w_h=0.7，s_vel=0.2，r_max=50.0；
- CBGS：开启；
- 检测 head 时序顺序：current、t-2、t-4、t-6、t-8；
- 第一层 feature KD：current 全通道 + t-2 全通道 + t-6 半通道，共 375 通道；
- 第二层 feature KD：保持原配置；
- response_loss x 0.6，lidar_distill_loss x 0.6。

注意：脚本文件名中的 wh08 是历史命名，当前代码实际 w_h=0.7。旧 checkpoint 使用训练时的原实现；上述坐标系、base floor 和时序 KD 修改只在重新训练后生效。

恢复训练：

```bash
python labeldistill/exps/lidardistill_convnextb_900x1600_J4_wl05_wh08_cbgs.py   --batch_size_per_device 2   --gpus 8   --checkpoint /mnt/nas_data/guqiupeng/checkpoint_nes/LidarDistill_convnextb_900x1600_J4_wl05_wh08_cbgs/checkpoints/last.ckpt
```

测试集推理：

```bash
python labeldistill/exps/lidardistill_convnextb_900x1600_J4_wl05_wh08_cbgs.py   --gpus 8   --predict   --checkpoint /path/to/epoch_19.ckpt
```

## 四、V3 调参搜索（find_best_v3，24 epoch）

ResNet-50 backbone，输入 256×704，BEV 128×128。6 个实验共用同一套 V3 蒸馏架构，仅在 mask / scale 超参上做单变量或组合搜索。

**公共设置**

| 项 | 值 |
|---|---|
| Mask | `QualityAwareMaskGeneratorV3`，`r_max=50.0`，`boost_small_medium=True` |
| Scale | `AdaptiveGTScalerV3`，`s_vel=0.2`，`r_max=50.0`， |
| 训练 | lr=4e-4，MultiStepLR milestone `[19, 23]`，EMA 开启 |
| 损失 | `response_loss` 不缩放，`lidar_distill_loss × 0.6` |

**各实验超参差异**（相对 `roi_v3` baseline 的搜索方向见「说明」列）

| 实验 | w_l | w_h | mu | 说明 |
|---|---:|---:|---:|---|
| `roi_v3` | 0.4 | 0.7 | 0.15 | baseline |
| `roi_v3_exp2` | **0.3** | 0.7 | 0.15 | 降低未匹配权重上界 |
| `roi_v3_exp3` | 0.4 | **0.8** | 0.15 | 提高高质量权重下界 |
| `roi_v3_exp4` | 0.4 | 0.7 | **0.20** | 增大 GT 放缩上限 |
| `roi_v3_exp5` | **0.3** | **0.8** | **0.20** | 宽权重区间 + 大 mu |
| `roi_v3_exp6` | 0.4 | 0.7 | **0.10** | 更保守的 GT 放缩 |

```
python labeldistill/exps/nuscenes/find_best_v3/LidarDistill_r50_128x128_e24_roi_v3.py      --gpus 8 -b 4
python labeldistill/exps/nuscenes/find_best_v3/LidarDistill_r50_128x128_e24_roi_v3_exp2.py --gpus 8 -b 4
python labeldistill/exps/nuscenes/find_best_v3/LidarDistill_r50_128x128_e24_roi_v3_exp3.py --gpus 8 -b 4
python labeldistill/exps/nuscenes/find_best_v3/LidarDistill_r50_128x128_e24_roi_v3_exp4.py --gpus 8 -b 4
```

## 五、续训 / 验证集评测

任一实验都可用 `--ckpt_path` 续训，或加 `-e` 在 nuScenes val 上评测（输出 mAP / NDS）：

```
# 续训
python <实验.py> --gpus 8 -b 4 --ckpt_path ./outputs/<exp_name>/checkpoints/last.ckpt

# 评测（单卡示例）
python <实验.py> -e --gpus 1 -b 4 --ckpt_path ./outputs/<exp_name>/checkpoints/last.ckpt

# 评测（多卡）
python labeldistill/exps/nuscenes/ablation_param/param_J4_wl05_wh08.py -e --gpus 4 -b 16 --ckpt_path ./outputs/<exp_name>/checkpoints/epoch_epoch=29.ckpt
```
